# workplace-installer: рабочее место для ИИ

Тестовая версия: может сломаться; если не получилось — пришлите отчёт

Установщик рабочего места: основной ИИ (Claude Code или Codex), второй ИИ для проверки, сторожа и навыки. Вы отдаёте его своему ИИ одной фразой. ИИ сам смотрит, что у вас уже стоит, показывает таблицу, ждёт одно «да» и ставит только недостающее. После установки вы хозяин: ИИ делает то, что вы просите, в любой папке, которую назовёте. Версия 4.0.0-rc.2. Mac и Windows.

## Одна фраза для вашего ИИ

Скопируйте и отправьте её Claude Code или Codex:

```
Прочитай и установи: https://github.com/mr-SuperNew/workplace-installer/releases/latest/download/INSTALL.md
```

Если ИИ не может открыть ссылку, скачайте файл INSTALL.md по этой же ссылке и вставьте его текст в чат целиком. Слова «прочитай и установи» в начале оставьте.

## Что получится

- Главная папка с правилами, памятью и списком задач. Новая и пустая: на установке ваши проекты и настройки остаются как есть.
- Два ИИ разных компаний. Один делает, второй проверяет его работу. По умолчанию Claude Code делает, Codex проверяет; можно наоборот («сделай основным Codex»). Любому из них можно отдать задачу целиком.
- Сторожа. Они не дают записать пароль в файл, останавливают опасную команду, напоминают записать правило после вашей поправки и предлагают проверку второго ИИ перед шагом, который нельзя отменить.
- Навыки: `/cross-check` (проверка вторым ИИ), `/end-session` (закрыть сессию и передать контекст), `/new-workspace` (папка под новую задачу или приём вашего готового проекта), `/doctor` (проверить и починить).
- Отчёт установки: что было, что поставлено, что вы делали руками, что изменилось вне главной папки.

## Что можно просить после установки

- «Посмотри мой проект в такой-то папке и скажи, что он делает», «продолжай проект, который я скопировал в главную папку».
- «Отдай эту задачу Codex», «сделай основным Codex».
- «Поставь ffmpeg», «обнови Claude Code»: ИИ покажет источник и команду и спросит «да».
- «Сделай коммит и push», «поменяй настройку в VS Code», «добавь строку в ~/.zshrc».
- «Используй ключ из .env в скрипте»: ключ работает в программе, но нигде не печатается.

## Три ограничения

Других «нет» у ИИ нет.

1. Секрет не показывается: значения ключей и паролей ИИ не печатает в чат, логи, отчёт и git и не отдаёт второму ИИ.
2. Пароль вводите вы: пароль компьютера и права администратора только ваши руками. ИИ даст команду и объяснит её.
3. Перед необратимым ИИ спросит «да»: перед удалением, правкой существующего файла вне главной папки, установкой или обновлением программы он покажет, что именно сделает.

## Для кого

Для тех, кто работает с ИИ каждый день и хочет, чтобы ИИ помнил дела, проверял себя и спрашивал вас на решающих шагах. Программировать не нужно. Нужны подписки: Claude (Pro или выше) для Claude Code и ChatGPT для Codex. Codex доступен и в бесплатном плане ChatGPT, но с малым лимитом. Цены сверьте на официальных сайтах перед оплатой.

## Что вы делаете руками

ИИ делает остальное, а вы только то, что он сделать не может:

- входите в свои аккаунты в браузере (Claude, ChatGPT);
- вводите пароль от компьютера, если установщик программы его просит;
- на Windows нажимаете «Да» в окне UAC;
- на Mac нажимаете «Установить» в системном окне Command Line Tools (оно приносит Python и git), если оно появилось; Homebrew для установки не нужен, команду с https://brew.sh вы запускаете сами, только если он понадобился вам для других программ и ваш Mac его поддерживает (Apple Silicon, macOS 15 или новее);
- по желанию ставите VS Code и расширения (модуль `vscode`);
- отвечаете «да» на план и на шаги, которые нельзя отменить.

## Как это устроено

1. ИИ скачивает архив выпуска с этой страницы GitHub и сверяет контрольную сумму sha256. Git для этого не нужен.
2. Разведка: ничего не меняет, определяет один из четырёх случаев (пусто, только Claude Code, только Codex, всё есть но разбросано) и показывает таблицу «есть, нет, версия».
3. Вы отвечаете «да» один раз. ИИ ставит недостающее официальными установщиками. Чужое на установке не трогает.
4. ИИ создаёт главную папку, подключает сторожей и навыки, проверяет сторожа выдуманным паролем, а проверяющий ИИ ловит ошибку, вшитую заранее.
5. ИИ пишет отчёт. Дальше вы хозяин.

Это инструкция для ИИ, а не гарантия: ИИ читает её и обычно соблюдает, но следите за его действиями. Подробности: [INSTALL.md выпуска](https://github.com/mr-SuperNew/workplace-installer/releases/latest/download/INSTALL.md), [случаи](docs/cases.md), [что пишется вне главной папки](docs/global-writes.md), [устранение неполадок](docs/troubleshooting.md).

## Обновление и ваши проекты

- Обновление: напишите ИИ «обнови установщик». Он сравнит версии, покажет, что изменится, и применит после вашего «да». Ваши правки он не затирает.
- Ваши проекты: назовите папку, и ИИ работает с проектом на месте или в копии внутри главной папки. Копию с историей git делает модуль `migrate-project` ([описание](modules/migrate-project/README.md)).

## Если не получилось

ИИ сам объяснит, что случилось, и предложит следующий шаг; можно написать `/doctor`. Подсказки по ошибкам: [docs/troubleshooting.md](docs/troubleshooting.md). Если захотите рассказать, как прошла установка, пришлите файл `install-report.md` из главной папки в Telegram: https://t.me/moneyBaires. Это необязательно.

Если у вас есть аккаунт GitHub, можно открыть вкладку Issues и выбрать форму «Сообщить о проблеме установки». В ней три поля: ваша система и случай, шаг, на котором остановилось, и файл отчёта. Пароли, ключи и почты в отчёт не попадают, но перед отправкой всё равно просмотрите файл.

## Для разработчиков

Тесты: `node tests/run-all.js`. Проверка перед публикацией: `node scripts/check-no-private.js .`. Сборка выпуска: `node scripts/build-release.js` (архив и sha256). CI гоняет тесты на macOS и Windows, Node 22, без секретов.
