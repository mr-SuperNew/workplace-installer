# Модуль vscode: редактор VS Code

**Коротко:** VS Code не обязателен, Claude Code и Codex работают и в терминале. Если человек выбрал VS Code, этот модуль даёт порядок шагов для редактора и одну настройку: «Claude Code: Toggle Focus view». Сам редактор и расширения ставит человек. ИИ подсказывает шаги и вносит любую настройку по вашей просьбе: копия файла настроек, разница «было, стало», ваше «да», правка.

Модуль лежит в `.workplace/modules/vscode/` главной папки. Подключать его не нужно: достаточно прочитать этот файл и запустить скрипт.

## Что делает человек руками

1. Ставит VS Code с официального сайта https://code.visualstudio.com/.
2. Ставит расширение Claude Code по инструкции Anthropic: https://code.claude.com/docs/en/vs-code (нужен VS Code 1.94 или новее) и входит в свой аккаунт Claude.
3. По желанию ставит расширение Codex (`openai.chatgpt`). Оно консольный Codex не заменяет: консольный ставит установщик отдельно.
4. Открывает редактор в пустом окне, не на своём рабочем проекте.

## Порядок шагов для редактора

Установщик доходит до этих шагов после создания главной папки.

1. **Открыть папку.** Файл, Открыть папку, выбрать ГЛАВНУЮ папку. На Mac пункт может называться «Файл, Открыть».
2. **Доверие папке.** Сначала проверьте в строке пути, что открыта именно новая главная папка. Потом нажмите «Доверяю этой папке» (Trust). В ограниченном режиме (Restricted Mode) редактор отключает автозапуск, и расширение Claude Code работает не полностью. Если папка не ваша или вы сомневаетесь, оставайтесь в ограниченном режиме: Claude Code в нём работает не полностью. Каждая новая папка спрашивает доверие заново: это штатно. Подробнее: https://code.visualstudio.com/docs/editing/workspaces/workspace-trust
3. **Панель Claude.** Значок-искра справа вверху, или Cmd или Ctrl+Shift+P и «Claude Code: Open». Если в редакторе есть «Open in Agents» или «Build with Agent», это встроенный GitHub Copilot, а не Claude.
4. **Перезапуск.** Когда установка подключила сторожей, полностью закройте редактор и откройте заново: обычной перезагрузки окна может не хватить. После перезапуска напишите ИИ `продолжи установку`.
5. **Focus view** (по желанию, раздел ниже).

Если вход в Claude открылся не в том браузере, скопируйте адрес со страницы входа в нужный браузер. Если терминал VS Code пишет «The terminal process failed to launch», установку это не блокирует: команды можно вводить в системном терминале.

## Настройка «Claude Code: Toggle Focus view»

Что делает: прячет в чате вызовы инструментов и промежуточную работу, оставляет ваши запросы и ответы Claude. Свёрнутое можно раскрыть одним щелчком, а индикатор показывает, какой инструмент работает сейчас.

Точный ключ в `settings.json`: `claudeCode.focusView` (логический, по умолчанию `false`, область действия `application`). Источник: `package.json` расширения Claude Code 2.1.286 (проверено локально 21.10.2026), там же команда `claude-vscode.toggleFocusView` с названием «Claude Code: Toggle Focus view» и сочетание клавиш `ctrl+alt+f`. Область `application` значит, что ключ действует только в настройках пользователя, а не в `.vscode/settings.json` проекта.

Три способа включить:

- **Руками через палитру команд.** Cmd или Ctrl+Shift+P, набрать «Claude Code: Toggle Focus view», Enter. Эту команду выполняет сам редактор и сам пишет файл настроек.
- **Сочетание клавиш.** Control+Alt+F на Windows. На Mac это Control+Option+F, а не Cmd+Option+F.
- **Скриптом.** Из главной папки:

```
node .workplace/modules/vscode/focus-view.js status
node .workplace/modules/vscode/focus-view.js apply
node .workplace/modules/vscode/focus-view.js apply --yes
node .workplace/modules/vscode/focus-view.js revert --yes
```

`status` только читает: показывает путь файла настроек и значение ключа. `apply` без `--yes` показывает, что изменится, и ничего не пишет. Покажите это человеку и после его «да» запустите `apply --yes` (файл настроек лежит вне главной папки, поэтому нужно «да»). Флаг `--yes` «да» не заменяет: модуль сверяет сообщения человека, которые записывает сторож главной папки. Нужно «да» в последнем сообщении и «VS Code» или «focus view» в двух последних (либо в плане, зарегистрированном командой `wp.js consent plan`); иначе `apply --yes` и `revert --yes` откажут и ничего не изменят. Скрипт меняет одну строку в файле настроек пользователя: добавляет `"claudeCode.focusView": true` или меняет `false` на `true`. Комментарии, порядок и чужие ключи не трогаются. Перед записью копия файла ложится в `.workplace/backup-update/`. `revert --yes` возвращает файл к состоянию до `apply`, но только если с тех пор его никто не менял; иначе откат отказывается и просит убрать строку руками.

Файл настроек пользователя:

| Система | Путь |
|---|---|
| Mac | `~/Library/Application Support/Code/User/settings.json` |
| Windows | `%APPDATA%\Code\User\settings.json` |
| Linux | `~/.config/Code/User/settings.json` |

Если VS Code ещё ни разу не запускался, папки с настройками нет, и скрипт откажется писать. Запустите редактор один раз.

## Любая другая настройка VS Code

Скрипт `focus-view.js` знает один ключ. Остальные настройки ИИ меняет вручную по вашей просьбе («поменяй размер шрифта на 15»):

1. Найти файл настроек пользователя (таблица выше). Прочитать его целиком.
2. Сделать копию: `node .workplace/core/cli/wp.js backup <файл>` (копия в `.workplace/backups/`) или обычное копирование.
3. Показать разницу: какая строка была, какая станет (например `"editor.fontSize": 13` на `"editor.fontSize": 15`). Комментарии, порядок и чужие ключи не трогать.
4. После вашего «да» внести одну правку. Файл настроек VS Code разрешает комментарии и запятые в конце: не пересохраняйте его целиком через JSON, меняйте нужную строку.
5. Сказать, что изменено и где лежит копия. Откат: вернуть файл из копии.

## Как это учитывается в сверке файлов вне главной папки

Файл настроек VS Code относится к классу «файлы, которые мог менять человек или VS Code». Скрипт пишет в журнал `STATE.md`, что настройка включена по «да» человека, и объявляет запись командой `state declare ~/путь#claudeCode.focusView` (файл и один ключ). Сверка `snapshot diff` считает эту запись объявленной (класс D, не тревога); любой другой изменённый ключ файла остаётся вопросом или тревогой. Названия ключей показываются в сверке, значения нет. Описание классов: `docs/global-writes.md`.
